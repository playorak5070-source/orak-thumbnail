# 오락 5070 썸네일 작업

유튜브 쇼츠·인스타그램 릴스 썸네일을 만드는 폴더입니다.
그림 그리는 AI를 쓰지 않고, **HTML을 크롬으로 사진 찍듯 뽑아** 만듭니다.

---

## 다른 PC에서 처음 시작할 때

### 1. 크롬이 있어야 합니다

구글 크롬으로 PNG를 뽑습니다. 없으면 설치해 주세요. **열어 둘 필요는 없습니다.**

### 2. 썸네일 뽑기

**`뽑기.bat`을 두 번 누르세요.** 끝입니다.

`오락폼\원본\`의 HTML을 전부 읽어 `오락폼\`에 PNG로 떨어뜨립니다.
폴더를 어디에 두든 됩니다 — 경로를 스스로 찾습니다.

> 완성 PNG는 저장소에 넣지 않습니다. 용량이 17MB라서, **다시 뽑는 편이 낫습니다.**

### 3. Claude에게 시킬 때 첫 마디

규칙은 전부 문서에 적혀 있지만 **Claude는 먼저 읽어야 압니다.**
새 PC에서 처음 시작할 때 이렇게 말해 주세요.

```
썸네일_제작규칙.md 와 오락폼/README_오락폼_규칙.md 먼저 읽고 시작해줘
```

## 폴더 구성

```
썸네일_작업\
  뽑기.bat                  ← 두 번 누르면 썸네일이 나옵니다
  README.md                 ← 이 문서
  썸네일_제작규칙.md         ← 채널 공통 규칙 (글자 수·색·크기·검수·작업판)
  작업기록.md                ← 무엇을 왜 바꿨는지, 날짜순
  타이틀3개_2026-11-16.md    ← 제목 뽑는 법과 결과
  제목벤치마킹_2026-11-16.md ← 조회수 분석 원자료

  오락폼\                    ← 완성 PNG가 여기 떨어집니다 (저장소에는 없음)
    README_오락폼_규칙.md    ← 폼 고정값과 뽑는 법
    원본\                    ← 만드는 파일. 넷이 함께 있어야 합니다
      orak.css              ← 공통 폼. 고치지 않습니다
      01~11_*.html          ← 주제마다 한 개
      _measure.html         ← 글자 폭 재는 도구
      사진\                  ← 로고와 주제 사진
      폰트\                  ← 나눔스퀘어 네오 Heavy

  작업판\                    ← 진행 상황을 한 장으로 본 페이지
    작업판.html + img\

  thumb\                    ← 주식 채널 썸네일 (별건)
```

### 왜 `원본\` 안에 다 같이 두나

HTML은 CSS·사진·글꼴을 **같은 폴더 기준**으로 찾습니다.
하나라도 밖으로 빼면 **글꼴이 조용히 바뀌거나 사진이 빈 칸**이 됩니다.
폴더째로만 옮기세요.

---

## 새 썸네일 만드는 법

1. `원본\06_오락4단계_쇼츠B.html`을 복사해 새 이름으로 저장
2. **제목 두 줄과 부제, 사진 이름만** 바꾸기
3. `_measure.html`로 글자 폭 재기 — 제목 **908px**, 부제 **848px**가 한계
4. `뽑기.bat` 실행
5. **뽑은 PNG를 열어 눈으로 확인** ← 빠뜨리면 안 됩니다

`orak.css`는 고치지 않습니다. 글이 안 들어가면 **크기가 아니라 글을 줄입니다.**

## 꼭 지키는 것

- **로고는 위에서 276px 고정** — 업로드하면 위쪽 14%가 잘립니다
- **글자 크기 고정** — 1줄 138px · 2줄 117px · 부제 56px (2줄과 부제는 이미 한계)
- **사진은 무료 사진 사이트에서** 찾는 것이 기본. 재사용·영상 캡처는 후보가 없을 때만
- **뽑은 PNG는 반드시 눈으로 확인**

자세한 내용은 `썸네일_제작규칙.md`에 있습니다.
