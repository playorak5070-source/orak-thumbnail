## 폴더 구성

완성된 **PNG만 바깥에 두고**, 만드는 데 쓰는 파일은 모두 `원본\` 안에 넣는다.

```
오락폼\
  01_그시절_겨울풍경.png     ← 쓰는 사람은 이 PNG들만 보면 된다
  02_동네모임_장소.png
  03_11월_제철음식.png
  04_오락4단계_쇼츠.png
  05_오락4단계_릴스.png
  06_오락4단계_쇼츠B.png
  07_오락4단계_릴스B.png
  _비교*.png                 ← 작은 크기에서 읽히는지 확인한 표
  README_오락폼_규칙.md      ← 이 문서

  원본\                      ← 만드는 파일. 평소에는 열 일이 없다
    orak.css                ← 공통 폼. 고치지 않는다
    폰트\NanumSquareNeo-Heavy.ttf
    사진\로고.png            ← 오락 5070 로고 (고정)
    사진\<주제사진>.jpg
    01~07 *.html             ← 새로 만들 때 06번을 복사
    _비교*.html
```

**HTML·CSS·사진·폰트는 반드시 같은 `원본\` 안에 함께 둔다.** 서로를 같은 폴더 기준으로
찾기 때문에, 하나라도 밖으로 빼면 글꼴이나 사진이 안 나온다.

## 주제마다 바꾸는 것

### 글자 크기는 이미 최대다 — 줄이지도 키우지도 않는다

2026-11-16에 **실제로 재서** 한계까지 키웠습니다. 5070 독자가 휴대폰 목록에서 읽어야 하기 때문입니다.

| 줄 | 지금 | 한계 | 무엇에 막히나 |
|---|---|---|---|
| 1줄 | **138px** | 144px | 「동네 모임 장소」 875px |
| 2줄 | **117px** | 118px | 「고르는 4가지 기준」·「제맛인 음식 6가지」 **9글자 줄** |
| 부제 | **56px** | 56px | 「도시락을 난로 위에 올려 본 세대라면」 826px |

쓸 수 있는 폭은 **제목 908px**(1080 − 좌우 86px), **부제 848px**(상자 안쪽 여백 30px씩)입니다.

**2줄과 부제는 이미 한계입니다.** 더 키우면 글자가 여백을 넘어 잘립니다.
글자를 더 키우고 싶으면 **크기가 아니라 글을 줄입니다.**

> **재는 법** — `원본\_measure.html` 을 헤드리스 크롬으로 열면
> 모든 줄의 픽셀 폭을 크기별로 표로 보여 줍니다. 새 글귀를 넣기 전에 여기서 먼저 재 봅니다.

### 제목 — 두 줄
```html
<div class="l1">11월에 먹어야</div>
<div class="l2">제맛인 음식 <span class="ac">6가지</span></div>
```
- **1줄은 7글자 이내, 2줄은 9글자 이내.** 넘으면 좌우 여백을 침범한다.
- 숫자(`5가지` `4가지` `6가지`)는 `<span class="ac">`로 감싸 빨갛게 한다.
- 길어서 안 들어가면 `orak.css`를 고치지 말고 **글을 줄인다.**
  (예: 「제맛인 제철 음식 6가지」 → 「제맛인 음식 6가지」)

### 부제 — 한 줄, 없어도 된다
```html
<div class="sub">장보기 전에 꼭 저장하세요</div>
```
14글자 이내.

### 사진
`사진\` 폴더에 넣고 `src`만 바꾼다. 가로가 긴 사진도 자동으로 가운데가 잘려 들어간다.

**AI로 만든 사진은 간판·포대에 엉뚱한 한글이 들어가 있는지 확인한다.** 있으면 그 자리만
흐리게 지운 판을 `<이름>_정리.jpg`로 따로 저장하고 `src`를 그쪽으로 바꾼다. 원본은 남겨 둔다.
(01번 `겨울골목.jpg` → `겨울골목_정리.jpg`: 위 간판 「암관산장(」, 가마니 「반 폭 / 윤가리 풀리칼」을 지움)

## 뽑는 법

HTML은 `원본\` 안에서 읽고, **PNG는 한 단계 위 `오락폼\`에 떨어뜨린다.**

```
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu \
  --hide-scrollbars --allow-file-access-from-files --window-size=1080,1920 \
  --virtual-time-budget=12000 \
  --screenshot="C:/Users/USER/Desktop/썸네일_작업/오락폼/06_오락4단계_쇼츠B.png" \
  "file:///C:/Users/USER/Desktop/썸네일_작업/오락폼/원본/06_오락4단계_쇼츠B.html"
```

`--allow-file-access-from-files` 가 빠지면 글꼴이 안 먹는다.
**뽑은 PNG는 반드시 눈으로 열어 확인한다.**
