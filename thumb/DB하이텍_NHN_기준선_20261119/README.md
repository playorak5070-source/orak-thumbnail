# DB하이텍·NHN 장마감 기준선 썸네일

2026-11-19 장마감 브리핑용으로 확정한 썸네일 양식입니다.

## 파일

- `02_썸네일_v5_기준선.png`: 최종 1280×720 PNG
- `기준선_썸네일.html`: 글자와 숫자를 바꿔 다시 출력할 수 있는 편집 원본
- `fonts/`: G마켓 산스 Bold·Medium
- `클로드_전달용_제작프롬프트.md`: 같은 디자인으로 새 썸네일을 만들 때 전달할 프롬프트

## 디자인 구조

1. 짙은 남색 배경과 왼쪽 노란 세로선
2. 상단 캡슐형 분류 문구
3. 왼쪽의 큰 기준 가격, 질문형 제목, 빨간 결론 배지
4. 오른쪽의 종목별 `기준선 → 종가` 카드 2개
5. 왼쪽 하단의 기준 날짜

## 수정 방법

`기준선_썸네일.html`을 편집기로 열고 아래 문구만 교체합니다.

- 상단 분류 문구
- 핵심 기준 가격
- 질문형 제목
- 결론 배지
- 종목명, 기준선, 종가, 차액
- 기준 날짜

브라우저에서 1280×720 크기로 캡처해 PNG로 저장합니다. 기존 파일을 덮어쓰지 말고 버전 번호를 올립니다.

## 필수 검수

- 1280×720 원본에서 잘림·겹침 확인
- 320×180 축소판에서 핵심 숫자·질문·결론 확인
- 한글·숫자·날짜와 장중/종가 구분 확인
- 오락 로고를 사용할 때는 공식 원본만 사용
